# 📚 Estudos-TI

Repositório dedicado aos meus estudos, exercícios práticos e experimentos em diferentes tecnologias da área de Tecnologia da Informação.

---

## 📖 Sobre

Este repositório reúne exercícios, desafios e pequenos projetos desenvolvidos durante meus estudos, cursos e graduação em Ciência da Computação.

O objetivo é registrar minha evolução técnica, consolidar conhecimentos e manter um histórico organizado do meu aprendizado em diferentes tecnologias.

---

## 📂 Estrutura do Repositório

```text
Estudos-TI
│
├── SQL
├── HTML-CSS
├── C
└── ...
```

Cada pasta contém exercícios organizados por tecnologia, podendo incluir:

* Exercícios práticos
* Desafios
* Scripts
* Projetos de estudo
* Materiais de apoio

---

## 💻 Tecnologias

| Tecnologia      | Conteúdo                                                   |

| 🗄️ SQL Server  | Consultas, JOINs, Modelagem de Dados |
| 🌐 HTML5        | Estrutura de páginas                                       |

> Novas tecnologias serão adicionadas conforme o avanço dos meus estudos.

---

## 🎯 Objetivos

* Praticar conceitos aprendidos em aula e em cursos.
* Desenvolver raciocínio lógico e boas práticas de programação.
* Organizar meus estudos por tecnologia.
* Registrar minha evolução como estudante de Tecnologia da Informação.
* Criar uma base de consulta para estudos futuros.

## 📌 Observações

Este repositório possui finalidade exclusivamente educacional.

Alguns exercícios representam soluções de atividades acadêmicas e desafios práticos, podendo ser revisados e aprimorados conforme a evolução do meu conhecimento.
